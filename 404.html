Self-Correcting Agentic RAG via Memory-Grounded Failure Localization

Haoyang Zhong, Yifei Sun, Shiwei Liu, Jie Li,
Chunping Wang, Yang Yang

Finding where reasoning goes wrong—and using memory to repair it at the source.

Paper Code
Research overview+

LoCoRAG is a globally self-correcting agentic RAG framework. It separates retrieved evidence from intermediate conclusions in a persistent dual memory, then uses these memories to localize the root cause of a failure. A matched repair can refine a local step, revise the decomposition, or roll back an upstream mistake and regenerate downstream reasoning.
