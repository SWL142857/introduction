学习专题 / Learning

学习线不按课程名称收藏知识，而按“下一次我能解决什么问题”组织能力。

课程提供基础，论文提供问题，实验暴露理解的缺口，项目则迫使这些知识共同工作。这里试着把四者连成一条能够反复回到现场的路线。

推荐路线

  1. 先看 我的学习与科研资料地图，理解全部资料如何分成六条主线。
  2. 再看 从机器学习课程到科研底座：我的基础能力路线，补全机器学习、视觉、图学习和系统基础。
  3. 接着看 LLM Systems 学习路线：从 MiniTorch 到 RLHF，进入训练、推理和系统层。
  4. 最后看 数据挖掘实验线：从房价预测到合同审阅，把实验组织和可复现交付串起来。

学习资料主线

主线 代表内容 能力目标
大模型基础 NLP、机器学习与 Transformer 练习 理解训练、评估、后训练和 Agent 的共同底座
LLM Systems 自动微分、CUDA、分布式训练、推理与 RLHF 看见模型能力背后的系统代价与工程约束
图学习与推理 GNN、异构图、关系数据库推理、GraphRAG 用结构处理多实体、多关系与多跳问题
视觉与深度学习 CNN、Transformer、CLIP、DINO、Diffusion 建立表征学习与生成模型的基础直觉
数据挖掘与实验 数据清洗、基线、指标诊断与结构化输出 把实验组织成可复现、可比较的证据

学习原则

  • 用输出检验理解：能解释、能复现、能比较，才算真正掌握。
  • 保留错误的形状：记录错误假设和失败实验，比只保留正确结论更有复用价值。
  • 让知识发生连接：每条学习线至少接向一个研究问题或工程项目。
  • 尊重内容边界：不公开受限答案和隐私材料，只分享可迁移的方法与经验。
