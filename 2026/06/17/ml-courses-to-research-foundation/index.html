从机器学习课程到科研底座：我的基础能力路线

发表于2026-06-17|更新于2026-08-13|Learning
|浏览量:

科研和项目做久了，很容易被最新名词牵着走。但回头看，真正支撑长期研究能力的，还是那些基础课程：机器学习、图学习、视觉、强化学习、图形学、编译和系统。

这篇把机器学习、NLP、视觉、图学习、强化学习、图形学与系统课程放在同一张能力地图里。重点不是课程名，而是这些基础如何在新的研究问题里重新汇合。

机器学习与大模型作业线

ML/ 里的作业覆盖了很多现代大模型主题：

  • RAG with Agents
  • Understanding LLM / Transformers
  • Training Transformer
  • Fine-tuning
  • Forgetting
  • Model Editing
  • Model Merging
  • Diffusion

这条线的特点是直接贴近现在的 LLM 应用，但仍然需要基础能力支撑。例如 fine-tuning 不只是调一个 LoRA 参数，背后涉及数据分布、遗忘、泛化、评估和资源约束；model editing 和 model merging 也不是魔法，而是参数空间、任务冲突和知识定位问题。

ANLP：语言模型知识的横向展开

ANLP/ 的课件形成了一张现代 NLP 主题图：

  • word representation 和 text classification
  • language modeling 和 sequence modeling
  • attention 和 Transformer
  • pretraining、finetuning、posttraining
  • decoding、prompting、evaluation
  • RL、agents、long context
  • efficient inference、quantization、多模态

这组材料适合用来补全概念边界。比如做 RAG 时会遇到 long context 和 evaluation，做推理服务时会遇到 efficient inference 和 quantization，做 Agent 时会遇到 prompting、tool use 和 posttraining。

CS231n：视觉和深度学习基本功

cs231n/ 的作业是深度学习基础训练：

  • KNN、softmax、two-layer net、fully-connected nets
  • BatchNorm、Dropout、CNN
  • PyTorch
  • RNN captioning、Transformer captioning
  • CLIP、DINO、自监督学习
  • DDPM diffusion

这条线的价值在于把神经网络从“调用库”还原成 layer、loss、gradient 和 optimizer。视觉任务也训练了一种非常重要的直觉：representation 的质量、数据增强、归一化和评估方式会直接决定系统上限。

CS224W：图学习和网络结构

cs224w/ 对当前 RAG/Memory 研究尤其重要。图学习训练的是另一种表示方式：节点、边、邻居、路径、社区、同质/异质图、message passing、GNN。

当我做 GraphRAG 或招聘图记忆系统时，很多问题都会回到图学习：

  • 什么样的边是有意义的？
  • 相似边应该全局建还是局部建？
  • 节点特征如何和结构特征结合？
  • 什么时候用 GNN，什么时候用规则投影更稳？
  • 图结构如何评估质量？

图不是万能表示，但它很适合表达关系和可解释路径。

强化学习：从预测到决策

RL-notes/ 是 CS285 风格的中文学习笔记，覆盖 imitation learning、policy gradient、actor-critic、value function、Q-learning、model-based RL、exploration、offline RL、IRL、soft optimality、RL and Language Models 等。

强化学习的核心不是“训练游戏 AI”，而是处理交互式决策。对于 LLM 和 Agent，RL 重新变得重要，因为 Agent 面对的是：

  • 不完全信息
  • 长期目标
  • 工具调用代价
  • 环境反馈
  • 人类偏好
  • 失败恢复

这也是为什么 RLHF、RLAIF、Agentic RL 和自我改进会成为大模型后训练的重要方向。

系统、编译和 C++ 基础

大二下/、大三上/、Compiler/、cp-3230101959/、GAMES101/ 这些目录看起来更传统，但它们提供的是工程底盘：

  • C++ 数据结构和内存管理
  • MiniSQL、buffer、storage、parser
  • 编译原理和中间表示
  • 网络实验和系统接口
  • 图形学中的矩阵、投影、光栅化和几何直觉

做 AI 系统不能只懂模型。只要项目进入真实工程，就会遇到性能、内存、并发、文件格式、日志、部署、可复现和调试问题。

一条更稳的学习路线

如果把这些基础材料整理成路线，我会这样安排：

  1. Python / C++ / 数据结构：保证能把想法写成可靠程序。
  2. 机器学习基础：理解 loss、optimization、generalization。
  3. 深度学习和视觉：理解网络结构、训练技巧和表示学习。
  4. NLP / Transformer：进入大模型主线。
  5. 图学习：支撑 GraphRAG、Memory 和结构化推理。
  6. 强化学习：支撑 Agent、RLHF 和长期决策。
  7. 系统课程：支撑训练、推理、部署和性能优化。

前沿研究总是在变，但基础能力会反复复利。一个稳定的学习系统，不是把所有课程都学完，而是知道遇到问题时应该回到哪一层补课。
