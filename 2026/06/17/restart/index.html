|浏览量:

这个博客重新整理了一次：保留 Hexo 和 GitHub Pages 的轻量发布方式，换成更现代的 Butterfly 主题，让这里更适合长期记录技术学习、项目复盘和研究阅读。

This blog has been refreshed with Hexo, GitHub Pages, and the Butterfly theme. It is meant to be a long-running place for technical notes, project retrospectives, and research reading.

会写什么

  • AI、机器学习与图学习
  • RAG、智能体和工程实践
  • 系统设计、工具链和实验记录
  • 读论文、做项目和复盘时留下来的想法

为什么重构

默认模板适合初始化项目，但不适合作为长期博客的门面。新的版本会把首页、归档、标签、分类和关于页都整理出来，让内容结构更清楚，也更适合继续扩展。

后续文章会逐步补上。先把门面擦亮，再慢慢把内容填进去。
