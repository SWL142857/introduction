导览 / Start Here

如果你第一次来到这里，不必从最新文章开始。

这个博客更像一张持续生长的研究地图：文章记录具体问题，专题连接相邻问题，项目复盘则保留从想法到验证的完整路径。你可以沿一条主线深入，也可以从一个正在困扰你的问题出发。

三种进入方式

  • 想快速认识我：先读 我的学习与科研资料地图，再去关于页。
  • 正在做 AI 研究：从 RAG 到 GraphRAG 开始，继续读 Agent Memory 与关系图推理。
  • 正在把 Demo 做成系统：从 从 Demo 到可审计系统 开始，关注评估、失败状态与人工边界。

五篇起点

  1. 我的学习与科研资料地图：先看全局，理解课程、研究与项目如何连接。
  2. RAG 到 GraphRAG：我的检索增强生成研究笔记：进入当前最重要的研究主线。
  3. Agent Memory 与图记忆系统：从论文到招聘场景：观察“记忆”如何从上下文变成结构。
  4. 工程项目复盘：从 Demo 到可审计系统：看一次实现如何跨过可用与可信之间的距离。
  5. LLM Systems 学习路线：从 MiniTorch 到 RLHF：补齐模型背后的训练、推理与系统底座。

这五篇共同回答一件事：我如何把分散的学习材料变成问题框架，再把问题框架变成可以验证的工程。

四条主线

研究 / Research

围绕 RAG、GraphRAG、Agent Memory 与关系图推理，研究结构如何进入检索、记忆与评估。

进入研究专题

项目 / Projects

保留输入、约束、实现、评估与失败状态，让项目不只“能跑”，也能被复查与继续。

进入项目专题

学习 / Learning

把课程、论文与实验组织成能力地图，让每一次学习都能接到下一个研究问题。

进入学习专题

工程 / Engineering

关注 Demo 之后的状态、审计、可观测性与人工边界，也记录工具如何被真正交付。

进入工程专题

现在正在做什么

  • 整理大三阶段的课程、科研、比赛与项目，把散落的材料重写成可以公开阅读的知识线索。
  • 聚焦 GraphRAG、Agent Memory、LLM Systems、关系数据推理与可复现 AI 工作流。
  • 用中文完成主要论述，同时保留必要的英文概念，减少翻译造成的语义损失。

一个阅读约定

这里记录的是阶段性判断，不是假装完整的标准答案。

  • 我会区分事实、推断与个人判断，尽量给出证据来源和推理路径。
  • 不公开受限作业答案、隐私数据或未授权材料，只提炼可迁移的方法。
  • 文章会随着理解更新；比起一次写对，我更在意留下可修正的路径。

如果一篇文章最终能够帮你少走一步弯路，或更准确地提出一个问题，这张地图就有了价值。
