从这里认识我 / Start Here

你好，欢迎来到我的小小互联网角落。

这里不是一份按主题严格分类的知识库，也不是只展示高光时刻的作品集。它更像一本不断变厚的手记：有生活片段，有学习留下的痕迹，有做过的东西，也有不同阶段尚未想明白的问题。

你可以这样开始

  • 想先认识我：去看关于我，或者从生活片段开始。
  • 想看我的成长路线：读 我的学习与科研资料地图，再沿学习专题继续。
  • 想看我做过什么：从 从 Demo 到可审计系统 或项目页进入。

没有固定顺序。博客本来就应该允许偶然相遇。

这里会记录什么

生活 / Life

普通日子、去过的地方、当时的心情和生活里的小发现。不是每件事都要有结论。

去看看生活片段

学习 / Learning

课程、阅读、实验与理解发生变化的过程。既记录学会了什么，也保留曾经卡住的地方。

沿着学习轨迹走走

思考 / Thinking

对技术、研究和选择的阶段性判断。它们不是标准答案，只是某个时刻认真想过的坐标。

阅读阶段思考

创作 / Making

项目、工具和作品，以及从想法走到实现时发生的取舍、失败与收获。

看看做过的东西

此刻的我

  • 正在整理大学阶段的课程、科研、比赛和项目，让它们成为一条看得见的成长轨迹。
  • 正在学习 GraphRAG、Agent Memory、LLM Systems 和关系数据推理。
  • 也在提醒自己：不要只记录完成了什么，还要记录当时怎样生活、怎样犹豫、怎样慢慢改变。

关于这里的约定

  • 文章是阶段性的，旧想法可以被新经历修改。
  • 不公开隐私、受限答案或未授权材料，但会留下可迁移的方法和真实感受。
  • 不强迫每篇文章都“有用”。有些文字只负责帮未来的我记住今天。

如果你愿意，希望这里不只让你看到我学过什么，也能看到我是怎样一路走到这里的。
